# Aula 14 - Matrizes em C

## Atividade para entrega
- `01_matriz_fixa.c` - matriz 2x2 com valores definidos no codigo, exibida como tabela
- `02_matriz_leitura.c` - le 4 valores do usuario e exibe a matriz 2x2
- `03_soma_matriz.c` - matriz 3x3 e soma de todos os elementos

## Revisao de conteudo
1. **Vetor x matriz:** o vetor tem uma dimensao (um indice); a matriz tem duas (linha e coluna, dois indices).
2. `int dados[3][4]` possui 3 x 4 = **12 elementos**.
3. Usamos dois `for` aninhados: o externo percorre as linhas e o interno percorre as colunas de cada linha.
