# Aula 15 - Matrizes em C: Aplicacoes praticas

## Exercicio para entrega
- `01_cinema.c` - matriz 3x4 de assentos; conta ocupados e disponiveis

## Exercicios de fixacao
1. `02_soma_matriz_2x3.c` - le uma matriz 2x3 e soma os elementos
2. `03_media_alunos.c` - notas de 3 alunos em 2 provas e media de cada um
3. `04_contar_pares.c` - conta os valores pares de uma matriz 3x3
4. `05_maior_valor.c` - maior valor de uma matriz 3x3

## Relembrando
1. Vetor tem uma dimensao; matriz tem duas (linhas e colunas).
2. `int numeros[3][4]` armazena 3 x 4 = **12** elementos.
3. Dois `for`: um percorre as linhas e o outro as colunas.
4. `numeros[1][2]` = **60**.

## Perguntas do material
- **Por que `totalProduto` e inicializada com zero dentro do primeiro `for`?** Para que cada produto (linha) comece a soma do zero; se ficasse fora, o total de um produto seria acumulado no seguinte.
